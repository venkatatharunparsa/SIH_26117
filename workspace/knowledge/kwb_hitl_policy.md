## POL-KWB-03 · Human verification before draft

**Policy owner:** Compliance desk (synthetic)  
**Applies to:** All KWB soft-copy drafts (DOCX / PPTX)

### Rules
1. **Confirm extract** — Any attached README, OCR stub, or pasted text must be
   human-confirmed before it is treated as task input.
2. **Company-doc match** — Extracts are checked against granted shelves
   (fixtures, SOP, knowledge). Empty retrieve → abstain / NOT FOUND (fail closed).
3. **Cite review** — Operator reviews citations before draft generation.
4. **Self-check draft** — Operator self-checks the DRAFT artefact version before export leave.
5. **Export leave ends the path** — Soft copy only; not CERT; no in-app forward-accept.

### Slide / brief drafts

`slide_brand_rules.md`. Status banner must read **DRAFT — NOT A PLANT RECORD**.
