# Commercial Platforms

| Product | Position | Limitations or qualification needed |
|---|---|---|
| Google Distributed Cloud Air-Gapped | Cloud-like infrastructure and AI in disconnected environments | Expensive, infrastructure-heavy, requires customer-specific integration and accreditation |
| Azure Local/disconnected operations | On-premise/disconnected Azure platform | Still requires enterprise architecture, licensing and application integration |
| AWS Snowball Edge | Local/disconnected compute and storage | Edge appliance, not a full industrial knowledge-work suite; AWS has announced Snowball discontinuation for new customers by end-2026 |
| IBM watsonx.governance | AI governance across cloud and on-premise | Governance platform, not automatically an industrial document/entity/workflow solution |
| Enterprise private-cloud LLM platforms | Managed local or private inference | Vary in true air-gap capability, document extraction and industrial integrations |

Google markets an air-gapped Distributed Cloud option for strict residency and security requirements. Microsoft documents disconnected Azure Local operation without a connection to Azure public cloud. IBM states that watsonx.governance supports governance across cloud and on-premise environments.

These platforms solve infrastructure or governance layers. They do not automatically solve:

- Equipment-tag linking
- P&ID revision awareness
- Inspection-point alignment
- Tender bidder segregation
- MOC action closure
- Permit context
- Work-order/historian correlation
- Word/Excel/PPT templates used by a specific PSU
