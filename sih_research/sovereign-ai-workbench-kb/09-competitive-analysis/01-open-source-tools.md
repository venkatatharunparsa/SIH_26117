# Open-Source Tools

| Product | Strength | Weakness for industrial deployment |
|---|---|---|
| Ollama | Easy local model serving | Not a complete document-governance or workflow platform |
| LocalAI | OpenAI-compatible local inference | Requires engineering for production security and enterprise workflows |
| GPT4All | Simple local chat and document use | Limited industrial connectors, governance and agent workflows |
| Jan | Local desktop model interaction | Not an enterprise multi-user platform |
| LM Studio | Convenient local model testing | Primarily a developer/desktop tool |
| PrivateGPT | Local RAG orientation | Needs production hardening, connectors, permissions and workflow layers |
| AnythingLLM | Local/RAG workspace capability | Industrial entity resolution, revision control and complex approvals require custom work |
| Open WebUI | Multi-model self-hosted interface, knowledge features and team permissions | UI and general RAG are not equivalent to industrial document control or sector workflows |
| LangChain/LlamaIndex | Agent/RAG building blocks | Frameworks, not a finished governed product |
| Vector databases | Retrieval infrastructure | Do not inherently understand revisions, clearance, asset identity or approval state |

Open WebUI documentation confirms model integration, knowledge management, extensibility and group permissions when used with local model servers such as Ollama. That is useful infrastructure, but it is not a complete refinery/PSU workbench.
