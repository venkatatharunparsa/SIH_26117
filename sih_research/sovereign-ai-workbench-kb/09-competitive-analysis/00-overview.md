# Competitive Analysis Overview

The market is crowded with models, RAG frameworks, vector databases, local chat interfaces, cloud infrastructure and governance dashboards. The missing layer is a deployable, security-aware operational knowledge system.

## What exists

| Category | Examples | What they solve |
|---|---|---|
| Local model servers | Ollama, vLLM, LocalAI | Model inference |
| Local chat UIs | GPT4All, Jan, LM Studio, Open WebUI | Conversational interface |
| RAG frameworks | LangChain, LlamaIndex, Haystack | Retrieval and agents |
| Vector databases | Chroma, Qdrant, Milvus, FAISS, pgvector | Semantic search |
| OCR tools | Tesseract, PaddleOCR, EasyOCR, Surya, DocTR | Text extraction |
| Commercial platforms | Google Distributed Cloud Air-Gapped, Azure Local, AWS Snowball Edge | Infrastructure |
| Governance | IBM watsonx.governance | AI governance |
| Indian AI | Bhashini, AI4Bharat, BharatGen, AIKosh, Sarvam, Krutrim | Models and datasets |

## What is missing

The missing layer is a deployable, security-aware operational knowledge system that understands:

- Assets
- Tags
- Revisions
- Approvals
- Work orders
- Contracts
- Incidents
- Standards
- Roles
- Document lineage
- Real deliverables
