# Document Types Glossary

## Engineering
- **P&ID** — Piping and Instrumentation Diagram
- **PFD** — Process Flow Diagram
- **Datasheet** — Equipment specification
- **Isometric** — 3D piping drawing
- **Line List** — Pipeline inventory
- **Cause-and-Effect Diagram** — Trip logic
- **HAZOP Report** — Hazard and Operability Study
- **MOC Form** — Management of Change

## Operations
- **Shift Log** — Record of shift events
- **Handover Note** — Summary for incoming shift
- **SOP** — Standard Operating Procedure
- **Startup/Shutdown Procedure**
- **Emergency Procedure**
- **Permit to Work**
- **Isolation Certificate**
- **Daily Production Report**
- **Abnormal Situation Report**

## Maintenance and inspection
- **Work Order**
- **Breakdown Report**
- **RCA Report** — Root Cause Analysis
- **Vibration Report**
- **Thickness Measurement Report**
- **NDT Report** — Non-Destructive Testing
- **Inspection Report**
- **RBI Assessment** — Risk-Based Inspection
- **FFS Assessment** — Fitness-for-Service
- **Turnaround Work Pack**

## HSE and compliance
- **Incident Report**
- **Investigation Report**
- **HAZOP Action Tracker**
- **MOC Review Sheet**
- **Environmental Monitoring Report**
- **OISD Compliance Report**
- **Factory Act Report**

## Commercial and finance
- **Purchase Requisition**
- **Tender Document**
- **Technical Bid Evaluation**
- **Commercial Bid Evaluation**
- **Comparative Statement**
- **Negotiation Note**
- **Purchase Order**
- **Contract**
- **Budget**
- **Financial Statement**
- **Board Note**
- **Approval Note**

## Cross-sector document types
- **Government**: File noting, cabinet note, RTI reply, audit response, legal opinion
- **Banking**: KYC file, credit note, sanction letter, investigation report
- **Legal**: Pleading, affidavit, judgment, case diary, evidence
- **Defence**: System requirement specification, test plan, configuration baseline, non-conformance report
