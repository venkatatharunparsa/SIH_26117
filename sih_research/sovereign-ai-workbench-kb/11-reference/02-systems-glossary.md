# Systems Glossary

## Real-time control
- **DCS** — Distributed Control System: Main process control system
- **SIS** — Safety Instrumented System: Independent safety shutdown system
- **PLC** — Programmable Logic Controller: Controls specific equipment
- **SCADA** — Supervisory Control and Data Acquisition: Monitors dispersed assets
- **F&G** — Fire and Gas System

## Data storage
- **Historian** — Time-series database (e.g., OSIsoft PI, Aspen IP.21)
- **LIMS** — Laboratory Information Management System
- **ERP** — Enterprise Resource Planning (SAP, Oracle)
- **EAM/CMMS** — Enterprise Asset Management / Maintenance Management
- **DMS** — Document Management System
- **PTW System** — Permit to Work System
- **MOC System** — Management of Change System
- **E-procurement Portal** — GeM, MRPL's own portal
- **HRIS** — Human Resource Information System

## Communication
- Email, shared drives, intranet, chat, electronic logbook

## AI workbench components
- **Policy engine** — Classification-driven model, index, export, and audit routing
- **Model registry** — Catalogue of approved models with metadata
- **Router** — Task classification and model selection
- **Vector index** — Embedding-based semantic search
- **Knowledge graph** — Entity and relationship store (assets, tags, documents, work orders)
- **Entity resolution engine** — Links equipment tags across documents
- **Agent orchestrator** — Multi-step workflow execution
- **Sandbox** — Isolated code execution (Python, R)
- **Audit log** — Immutable record of prompts, sources, calculations, outputs, reviewers
