# MeghRaj and NIC Cloud

## NIC National Cloud

NIC's National Cloud and MeghRaj provide government cloud infrastructure. The National Government Cloud offers private, public and hybrid services and on-premise-style secured data-centre services.

## Services available

- Private cloud (dedicated to one department)
- Public cloud (shared government infrastructure)
- Hybrid cloud
- On-premise-style secured data-centre services
- Managed services (security, backup, disaster recovery)

## Relevance to AI workbench

MeghRaj/NIC cloud can host:

- Moderate-sensitivity AI workloads
- Internal administrative document processing
- Non-classified government document search
- Multilingual translation and OCR
- Employee training assistants

For high-sensitivity workloads (Confidential and above), on-premise or air-gapped deployment is still required.

## Deployment tiering

| Data classification | Suggested deployment |
|---|---|
| Public | Any cloud |
| Internal | MeghRaj/NIC cloud or departmental private cloud |
| Restricted | Government cloud or on-premise |
| Confidential | On-premise or accredited private cloud |
| Secret/Top Secret | Air-gapped or accredited classified environment |

## Cloud sovereignty framework (proposed 2026)

A September 2026 report described a proposed government cloud-sovereignty framework considering air-gapping, provider independence, server location, foreign legal exposure and kill-switch risk. This is a contemporary policy signal, not yet evidence of a universally binding final rule.
