## 1. Banned on slides (hard)

| Ban | Why |
|---|---|
| “chatbot” / “chat application” / “chat UI” / “not a chatbot” | User rule + weak framing; say **workbench / deliverables** |
| CERT-In certified · DPDP compliant badge | Controls ≠ accreditation |
| Monitor A = CERT | Evidence pack only |
| OCR 99% · tokens/s as *our* result | Not measured |
| Plant ₹crore savings · prize money | Theatre |

| Fake prototype URL / QR | PDF must stand alone |
| Dual 70B in VRAM · G1 “full multi-model” without staging | Floor honesty |
| Internal WP-00…WP-24 labels | Screener jargon |
| Blank Team ID on final export | Corpus defect — fill it |
| In-app Approver / “AI approved the plant” | Integrity fail |
| “We built OpenHands / DeerFlow” | Patterns only |

## 2. Required honesty chips (keep visible)

- **DRAFT** · soft copy · **export leave** ends solution path  
- **Human checkpoints** — engineer confirms extract, citations, DRAFT, and sandbox results · human ultimate verifier  
- **Monitor A ≠ CERT** (evidence pack only)  
- **Ollama = inference only · no pull** (demo)  
- **Two task types · staged dual tags** when proven (`llama3.2:3b` / `qwen2.5-coder:7b`); never invent extra models  
- **Private LAN / on-prem Gateway** — do not print “fully air-gapped” unless NIC evidence exists  
- **Never write** DCS / SIS / EAM / ERP
